How to block websites on a Mac (Instagram, YouTube, TikTok, X)

Last updated: November 14, 2026

You can block any website on a Mac or MacBook for free with Screen Time, which is already built in. This guide shows the steps and the exact addresses to block for Instagram, TikTok, YouTube, X (Twitter), Reddit and Facebook. If you block one site and just open another, the stronger fix is to turn off the whole internet for a set time.

The quick answer

  • To block a few sites for free: use Screen Time, which is already on your Mac. Steps below.
  • To block one site for a set time: use a free blocker like SelfControl. See free internet blockers for Mac.
  • If you block one site and just open another: block the whole internet for a while instead. That’s what Vow does.

How to block a website on a Mac with Screen Time (free)

Screen Time is built into every Mac and MacBook. It costs nothing and needs no download.[1]

  1. Click the Apple menu, then System Settings, then Screen Time.
  2. Click Apps & Websites, then Restrictions.
  3. Under Websites, click Filtering and choose Limit Adult Websites. Then click Customize.
  4. Under Restricted, click +, type the website, like instagram.com, and click Done.
  5. Back in Screen Time, turn on Lock Screen Time Settings and set a passcode, so the block can’t be switched off in one click.

Good to know: Apple only promises it works in Safari. Other browsers, like Chrome or Firefox, may not follow it. And if you set the passcode yourself, you know how to undo it. If that’s a problem, ask a friend or family member to set the passcode for you.

Which addresses to block for each site

Most sites use more than one address. Block all of them, or the block has a hole.

How to block Instagram on a Mac

Add instagram.com to the Restricted list above. Reels and Explore are built to never end. On a Mac you mostly use Instagram in the browser, so blocking the website is enough for the Mac. Your phone needs its own limit.

How to block TikTok on a Mac

Add tiktok.com to the Restricted list above. The For You feed is the hardest one to put down. Block the website on your Mac, and keep the phone app out of reach while you work.

How to block YouTube on a Mac

Add youtube.com, youtu.be and m.youtube.com to the Restricted list above. Autoplay and the sidebar turn one video into an evening. Block all three addresses, or links from other sites will still open videos. Need one video for class? Download it first, then block.

How to block X (Twitter) on a Mac

Add x.com and twitter.com to the Restricted list above. Block both names. Old links still use twitter.com and quietly send you to X.

How to block Reddit on a Mac

Add reddit.com, www.reddit.com and old.reddit.com to the Restricted list above. Reddit has several addresses. If you block only one, the others still work.

How to block Facebook on a Mac

Add facebook.com and messenger.com to the Restricted list above. Block Messenger too if chats are what pull you back in.

Why blocking one site often doesn’t work

Block Instagram, and you open TikTok. Block TikTok, and you open YouTube. Block YouTube, and Reddit fills the gap. You end up adding sites to a list forever, and the list always has one you forgot.

If that sounds like you, stop blocking sites one by one. Turn off the whole internet for a set time instead. Then Instagram, TikTok, YouTube, X, Reddit and every other site are blocked at once, in every browser and app, and there’s nothing left to switch to.
